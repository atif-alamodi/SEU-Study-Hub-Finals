## ⌨️ اختصارات لوحة المفاتيح

- `Alt+1` أو `Ctrl+1` — الصفحة الرئيسية
- `Alt+2` — نظم التشغيل (OSC)
- `Alt+3` — الإحصاء (STA104)
- `Alt+4` — البايثون (PYT103)
- `Alt+5` — الإنجليزي (ELG201)

## 🛠️ المميزات

- ✅ تبويبات سريعة بين المواد دون إعادة تحميل الصفحة
- ✅ تحميل ذكي (lazy loading) للمواد عند فتح التبويب فقط
- ✅ صفحة هبوط تفاعلية ببطاقات للمواد
- ✅ تصميم متجاوب RTL لجميع الأجهزة
- ✅ حفظ آخر تبويب تم استخدامه
