📐 Grammar: Adjectives

Adjective — الصفة An adjective is a word that describes a noun. (كلمة تصف اسماً)
موضع الصفة:
1. قبل الاسم: "He is a kind man" — الصفة قبل الاسم مباشرة
2. بعد to be: "She is smart" — الصفة بعد am/is/are
القاعدة الذهبية: Adjectives are the SAME in singular and plural — ❌ "happys" ✅ "happy"

Examples from the curriculum:

  • She is beautiful.
  • My father bought a big car last year.
  • Nora is tall.
  • He has green eyes.
  • She wears new clothes.
  • The machine is fast.

📐 Grammar: Imperatives & Passive Voice

Imperatives — صيغة الأمر (من المنهج)

Imperatives — for instructions جملة تبدأ بالفعل مباشرة بدون فاعل ظاهر. تُستخدم في التعليمات التقنية وأدلة الاستخدام.
Download the file. | Open the application. | Follow the instructions. | Connect the device.
Imperative (أمر)NOT (خطأ شائع)
Download the file. ✅You download the file. ❌ (for instructions)
Open the application. ✅Downloading the file. ❌
First, activate the system. ✅First, the system activate. ❌

Passive Voice — المبني للمجهول (من المنهج)

Passive Voice — for processes نُركّز على ما يُنجَز (المفعول) بدلاً من من يُنجزه (الفاعل). شائع في الكتابة التقنية.
Object + is/are + past participle
The file is uploaded. | The system is activated. | The task is completed.
Active (مبني للمعلوم)Passive (مبني للمجهول)
The user uploads the file.The file is uploaded. ✅
The system activates.The system is activated. ✅
The user completes the task.The task is completed. ✅
